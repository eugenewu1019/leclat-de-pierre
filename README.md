## 📖 Introduction (專案簡介)

**L'ÉCLAT DE PIERRE** (石之光) is a high-end digital gallery for a conceptual patisserie where architecture meets pastry. Inspired by **Brutalism** and **Deconstructivism**, the project redefines the dessert experience through grey-scale aesthetics and structural precision.

**L'ÉCLAT DE PIERRE** 是一個融合「建築美學」與「法式甜點」的高端數位藝廊。深受**野獸派 (Brutalism)** 與**解構主義**啟發，本專案透過灰階美學與精確的結構計算，重新定義甜點的感官體驗。

Created by an architect-turned-pastry-chef, every piece in this collection is treated as a miniature building, where ingredients are construction materials and the plate is the site.

由建築師轉型的甜點師創立，展覽中的每一件作品都被視為一座微型建築：食材即建材，盤中即基地。

## ✨ Key Features (核心特色)

-   **🏗️ Architectural "Blueprint" Mode (建築藍圖模式)**:
    -   Interactive scanning effect that transforms dessert photos into technical CAD-style blueprints.
    -   Detailed structural analysis: Layer thickness, construction steps, and flavor mechanics.
    -   互動式「掃描」效果，將甜點實拍照即時轉化為 CAD 技術線稿，內含層次厚度、施工流程與味覺力學分析。

-   **🖼️ Snap-Scroll Exhibition (藝廊級滾動體驗)**:
    -   Custom smooth-snap scrolling implementation for a deliberate, page-by-page discovery of the collection.
    -   Atmospheric blur and depth-of-field transitions as items enter the viewport.
    -   客製化平滑吸附滾動，提供「一滑一頁」的觀展手感，伴隨景深模糊與大膽的文字排版過渡。

-   **🎨 Brutalist Aesthetic (野獸派灰階美學)**:
    -   Monochromatic palette featuring concrete textures, glassmorphism, and editorial typography.
    -   High-end interaction design including magnetic effects and noise-textured backgrounds.
    -   純粹的灰階色調，結合清水模質感、毛玻璃效果與雜訊紋理，營造極致的專業與冷峻感。

-   **🌍 Bilingual Support (中英雙語系)**:
    -   Full i18n support for Traditional Chinese and English.
    -   完整支援繁體中文與英文選單切換。

## 🛠️ Tech Stack (技術棧)

-   **Core**: [React 19](https://react.dev/) & [Vite](https://vitejs.dev/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS for complex blending modes and concrete textures.
-   **Animations**: Custom CSS Transitions & Intersection Observer for performant scroll detection.
-   **Icons**: [Lucide React](https://lucide.dev/).
-   **Assets**: Optimized local imagery and AI-augmented technical sketches.

## 🚀 Getting Started (如何執行)

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/eugenewu1019/leclat-de-pierre.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run development server**:
    ```bash
    npm run dev
    ```
